Provably fair

Before each run we publish SHA-256(server seed). Every draw is u = HMAC-SHA256(seed, client:nonce:message), first 52 bits ÷ 252.

The run is split into segments. In segment k the multiplier is base × et × ln2 / 8 s, rounded down to the cent, and the helicopter catches the thief once it passes the crash point. Segment 0 (message seg:0): base 1.00, crash point r0 = floor(100 × 0.97 ÷ (1 − u)) ÷ 100, at least 1.00, so P(reach m) = 0.97 ÷ m. A jump (message jump:n) succeeds when u < 1/3 and pays 3 × m, then segment k + 1 (message seg:k) starts at base 3m with crash point base × 1 ÷ (1 − u), so P(reach m) = base ÷ m with no edge. A jump that would pass 10,000× pays exactly 10,000× and succeeds when u < m ÷ 10,000. The curve stops at 10,000× with an automatic cash-out. After the run the seed is revealed.

How to play SKYLINE

A thief, a sunset and a lot of rooftops. Play money only.

  1. Press RUN. The thief sprints across the roofs and the multiplier climbs.
  2. Gap ahead! A ring counts down. Press JUMP and one in three times the multiplier triples on the spot. Miss and the run is over.
  3. Or play it safe. Do nothing and a plank slides across the gap. The run carries on.
  4. Cash out any time. When the police helicopter's searchlight finds the thief, everything still running is lost.
